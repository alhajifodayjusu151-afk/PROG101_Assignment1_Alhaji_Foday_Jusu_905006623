# FloodWatch SL

A logical design (algorithm, pseudocode, flowcharts) for a community flood early-warning system in Sierra Leone.

## Course
PROG101 Principles of Programming Logic and Design, Limkokwing University of Creative Technology, Sierra Leone.

## Problem
Communities in flood-prone areas lack a simple, consistent way to turn rainfall and water-level readings into a clear warning.

## Solution
Inputs: community name, 24-hour rainfall (mm), water level (% of capacity), flood-prone (Y/N).
Output: risk level (LOW, MODERATE, HIGH, SEVERE), an alert message and a summary.
